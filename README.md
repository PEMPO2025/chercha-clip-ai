# CHERCHA CLIP AI — prueba 0.1
Sube estos archivos a un repositorio privado GitHub. En Railway, cuando decidas contratar recursos, despliega el repositorio usando el Dockerfile. Configura APP_PASSWORD con una contraseña nueva y larga. Opcional: AUTHORIZED_HLS_URL con una URL HLS HTTPS de una fuente propia o autorizada. Genera un dominio público en Networking. Usuario: admin. Escribe demo para probar una señal sintética, o pega la URL HLS configurada. Actualiza la galería durante la captura. Cada prueba dura máximo 120 segundos y produce segmentos de 15 segundos en 360x640, sin marca. Los archivos son temporales. No admite aún enlaces de páginas YouTube, selección IA ni publicación Facebook. No hay despliegue gratuito garantizado. No dejes el servicio activo innecesariamente.
